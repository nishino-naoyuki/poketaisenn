# ポケカ オンライン対戦ツール (src)

ビルド不要。`index.html` をブラウザで開くだけで動作します（`file://` 可）。
P2P通信のみ、PeerJS を CDN(unpkg)から読み込むためインターネット接続が必要です。

## モジュール構成（読み込み順）

| ファイル | 役割 |
| :--- | :--- |
| `js/data/cards.js` | サンプルデッキ、カード登録、エネルギー表示情報 |
| `js/data/deck-parser.js` | デッキコード解析・テキスト貼付読込・プリセット管理 |
| `js/util.js` | 共通ユーティリティ（シャッフル等） |
| `js/data/playmats-default.js` | プリセットプレイマット10種 |
| `js/state.js` | グローバル状態 `state` |
| `js/game/setup.js` | 対戦 / 一人回しのセットアップ |
| `js/ui/render.js` | 盤面描画・スマホ用ボトムシート |
| `js/ui/marquee.js` | 手札の範囲選択 |
| `js/ui/touch-dnd.js` | タッチ操作ドラッグ＆ドロップ |
| `js/game/hand-actions.js` | 手札・場のカード操作 |
| `js/game/actions.js` | 山札/使用カード/ダメカン/ターン終了/一人回しスワップ |
| `js/ui/modals.js` | 山札モーダル・ログ・トースト |
| `js/game/replay.js` | CSV出力・インポート・試合再現 |
| `js/ui/lobby.js` | ロビー（デッキプレビュー・モード切替） |
| `js/ui/playmat.js` | プレイマット選択・自作登録 |
| `js/net/p2p.js` | PeerJS による P2P 対戦同期 |
| `js/main.js` | 初期化・イベント登録・`actions` 定義 |

通常の `<script>` で読み込むため、モジュール間はグローバルスコープを共有します（ES Modules は `file://` で動作しないため不採用）。

## P2P対戦の使い方
1. 片方が「ルーム作成」→ 表示された6桁番号を相手に伝える
2. もう片方が番号を入力して「入室」
3. 双方が「対戦開始」を押すと、相手の盤面（バトル場・ベンチ・トラッシュ・枚数）が同期表示される

手札・山札・サイドの中身は送信されず、枚数のみ共有されます。スタジアムは共有ゾーンで、最後に変更した側が優先されます。
